barqr

QR codes and barcodes over HTTP. One stateless container.

barqr turns a string into a scannable image. Every option is available as a query parameter, so a barqr URL is the image — paste one straight into an <img src>. The same field names also work as a JSON body or a multipart form, because one decoder handles all three.

Do not expose this service directly to the internet.

    barqr is built to sit on an internal network and answer requests from your own code.
    It binds 127.0.0.1 by default and refuses to start on a wider address
    without API keys — but that guard is a safety net, not a licence to publish it.
